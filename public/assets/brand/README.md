# Opportunity FLOPs brand assets

Transparent PNG assets derived from the approved bold geometric mascot set.

- `flipflop-upright-{red,blue}.png`: upright slider/icon variants
- `flipflop-flying-{red,blue}.png`: rotatable airborne variants without motion marks
- `motion-lines.png`: independent animation overlay
- `favicon-mark.png`: repaired red/blue compact badge
- `mom-{red,blue}.png`: isolated mascot variants

The source reference is `work/imagegen/selected-reference.png`. Green-screen generation intermediates are retained in `work/imagegen/` for reproducibility and review.
